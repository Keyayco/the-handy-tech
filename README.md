# The Handy Tech — vanilla website

A responsive, no-build website concept for GitHub Pages.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

## Publish on GitHub Pages

1. Push the contents of this repository to `main`.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.

## Research boundary

The supplied repository was empty and no authoritative public profile or service listing could be reliably matched to The Handy Tech at 8 Baron St, Swartruggens, with the supplied phone number. The design therefore uses a clearly labelled adaptable service framework rather than asserting unverified qualifications, reviews, prices, history or an exact service menu.

Before launch, confirm: legal business name, service categories, service area, operating hours, WhatsApp response expectations, logo/brand assets, owner bio, photos, and any testimonials or credentials.
